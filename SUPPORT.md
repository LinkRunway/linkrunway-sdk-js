# Getting help

| You need                                                                | Where to go                                                                                                    |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| SDK setup and supported behavior                                        | The repository README and [developer guide](https://linkrunway.com/resources/developers)                       |
| A reproducible SDK bug                                                  | Open a bug report in the affected SDK repository                                                               |
| A feature or documentation improvement                                  | Open a feature request or pull request in the affected repository                                              |
| Account access, billing, a private workspace issue, or integration help | Email **support@linkrunway.com**                                                                               |
| A suspected vulnerability                                               | Follow the [security policy](https://github.com/LinkRunway/.github/blob/main/SECURITY.md) and report privately |

For technical reports, include the SDK version, runtime or device/OS, installation method, expected and actual behavior, and a minimal reproduction. Share redacted error messages and timestamps when helpful. Never post keys, cookies, private links, customer records, payment details, or unredacted logs.

Public issues are for reproducible project work, not private account support. Email is the support channel; there is no published phone-support service or guaranteed response time in this repository.
